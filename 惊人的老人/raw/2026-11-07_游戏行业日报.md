## 五、策划视角小结

1. **存量市场的立项起点，已经从「做一个新玩法」变成「盘点手上有什么 IP 资产」。** IP 产品吃掉 81.4% 的流水、TOP100 里 63% 是 IP 游戏，而原创 IP 市场 1467.83 亿元的增速（8.4%）低于引进授权 IP（11.2%）——说明买现成 IP 的确定性溢价还在扩大。不做 IP 的产品要么去抢那 18.6% 的非 IP 份额，要么一开始就把「可衍生、可联动、可跨媒介」写进世界观设计，否则立项时就已经输在资产结构上。
2. **买断制的品类红利正在从 RPG 转向动作与策略。** Steam 买断制时长动作类 +28%、策略类 +24%，RPG 反而 -14%，而《影之刃零》连续一周稳居国区热销第一。做买断项目时，动作手感和策略深度是可验证的时长抓手，纯叙事驱动的 RPG 需要更强的口碑门槛才能撑住留存；如果团队能力允许，把「动作 + 构筑」而不是「剧情 + 演出」放在玩法核心，容错率更高。
3. **二次元进入负增长后，档期与差异化成了仅剩的两个变量。** 上半年二次元手游 132.69 亿元、同比 -8.97%，乐元素仍选择跳过三测、把《白银之城》直接压到 12 月 14 日寒假前卡位，本质上是用档期换首发窗口。但跳过三测意味着手游端优化风险后置，对玩家是赌、对团队是压缩验证周期——这类决策只有在「画风差异化足够强、且长线更新已排到半年后」时才成立。
