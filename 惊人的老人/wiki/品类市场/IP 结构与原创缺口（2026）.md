# IP 结构与原创缺口（2026）

《2026 年中国游戏产业 IP 发展报告》给出了一组结构数字：**全年游戏 IP 市场规模预计 2992.3 亿元**，1—9 月 IP 产品流水占游戏市场 **81.4%**。

> 单一二手来源（11-07 日报转述报告发布方口径），`confidence: low`。报告由中国音数协 IP 工作委员会与伽马数据在苏州游戏 IP 生态大会上联合发布，属**行业自述口径**，不是审计数据。

## 数字

| 指标 | 数值 | 说明 |
|---|---|---|
| 游戏 IP 市场总规模 | 2992.3 亿元（预计） | 全年 |
| IP 产品流水占游戏市场 | 81.4% | 1—9 月 |
| 移动游戏流水 TOP100 中 IP 游戏数量占比 | 63% | 数量口径，非流水 |
| 原创 IP 市场 | 1467.83 亿元（+8.4%） | 金额口径 |
| 引进授权 IP 市场 | 1335.83 亿元（+11.2%） | 金额口径 |
| 衍生品官方旗舰店销售 | 101.71 亿元（预计） | 全年 |

## 怎么读这组数

**「81.4% 是 IP」和「原创只占 18.6%」是两句话，不是一句。** 原创 IP 本身也是 IP 产品，它算在那 81.4% 里面。真正落在非 IP 一侧的只有 18.6% 的流水——这是「没有可复用资产」的那部分市场。

第二层是增速差：原创 +8.4% 对引进授权 +11.2%，差 2.8 个百分点。按金额拆，原创一年增约 113.7 亿元，引进授权增约 134.5 亿元。**差距存在但并不悬殊**，而引进授权的基数还更小。

第三层是衍生：官方旗舰店 101.71 亿元，相对 2992.3 亿的总规模只有 3.4%。**IP 变现目前几乎全在游戏内，跨媒介的部分还很小。**

## 对立项的含义

如果这个结构成立，立项的起点会从「我要做一个什么玩法」变成「我手上有什么可用于复用的资产」。这句判断来自日报的策划视角，本文转述并标注为**生成方观点**。

可操作的部分是它给出的两个方向：

- 不做 IP 的产品，竞争的是那 18.6% 的非 IP 份额
- 想进 IP 一侧，要么买授权（确定性溢价，但要付授权费），要么把「可衍生、可联动、可跨媒介」写进世界观设计——**这是设计动作，不是发行动作**

## 反论与缺口

- **两项之和 ≠ 总额（本站核算）。** 原创 1467.83 + 引进授权 1335.83 = 2803.66 亿元，与 2992.3 亿的总额差 **188.64 亿元**。这块差额是什么（混合授权、自研非 IP、口径重叠），报告转述里没有交代。
- **「确定性溢价在扩大」的证据只有一年。** 2.8 个百分点的增速差，在行业自述数据里完全可能是基期效应或单笔大授权造成的一次性波动。一年的差不足以叫趋势。
- **81.4%（流水口径）与 63%（数量口径）经常被混用。** 前者说明钱集中在 IP，后者说明 IP 覆盖面广。用 63% 去推「IP 是必选项」会高估，用 81.4% 去推「非 IP 活不下去」会低估那 18.6% 里长期存在的小体量产品。
- **2992.3 亿与 101.71 亿都是「预计」。** 报告在发布时给的是全年预测，不是结算值。
- **未验证**：81.4% 的分母是「中国游戏市场实际销售收入」的哪个口径（全年还是同期），这决定它能不能和其他年份直接比。
